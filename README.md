# Muhammad Taha Bin Zaeem

The complete portfolio website lives in [`web/`](web/).

To run it locally:

```bash
cd web
npm install
npm run dev
```

The website source, assets, build configuration, documentation, and tests are all contained in `web/`. The previous profile README source is preserved at [`web/docs/profile-readme-source.md`](web/docs/profile-readme-source.md).
