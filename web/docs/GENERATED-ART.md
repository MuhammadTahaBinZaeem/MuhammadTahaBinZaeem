# Campus artwork

Generated with the built-in imagegen tool, using actual campus photographs as architectural references. These are decorative illustrations, explicitly described as illustrations in the image captions and alt text. Original personal photographs stay in the evidence collections.

The PNG masters were copied into the project as optimized WebP files. No external image host or generation service is required to run the site.

### Government College University, Lahore

Asset: `public/media/education/gcu-campus-art.webp` (1800 × 600 WebP).

Reference: [GCU official campus image](https://gcu.edu.pk/uploads/images/2021-07-0817967.jpg).

Prompt:

> Use case: stylized-concept. Asset type: wide cinematic university banner for a personal engineering portfolio. Create a detailed, beautiful painterly architectural illustration of the ACTUAL Government College University Lahore main building, using the attached photo strictly as architectural reference: preserve the red-brick Gothic central clock tower, pointed spire, arched facade, side wings, palms and terraced lawns. Landscape panoramic 3:1 composition, building occupies right two-thirds and full tower remains visible; left third atmospheric dark green shadowed lawn/sky with low detail for white website heading overlay. Sophisticated ink engraving mixed with hand-painted color, warm copper brick, jade greens and parchment gold, golden dusk glow and atmospheric depth. Refined premium editorial art with small etched drafting lines. No invented buildings, no additional towers, no people, no captions, no writing, no logos, no border. Illustration should clearly look like art, not a documentary photograph.
