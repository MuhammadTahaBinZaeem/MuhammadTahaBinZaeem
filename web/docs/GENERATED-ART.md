# Campus and chapter artwork

Generated with the built-in imagegen tool, using actual campus photographs as architectural references. These are decorative illustrations, explicitly described as illustrations in the image captions and alt text. Original personal photographs stay in the evidence collections.

The PNG masters were copied into the project as optimized WebP files. No external image host or generation service is required to run the site.

## Chapter atmospheres

Six original conceptual illustrations generated with the built-in imagegen tool. The existing NUST CEME illustration was supplied only as a style reference for warm lighting, emerald shadows, fine engraving and architectural depth. These scenes depict imagined creative spaces, not actual institutions, events or awards. Authentic personal and project photographs remain separate gallery records.

All delivery files are 1800 × 600 WebP, converted from the generated PNG masters with Sharp at quality 87. Change the backgrounds and personal introductions in `app/chapter-artwork.ts`; every background opens in the shared viewer. No generated portrait is used: the accompanying author image is the official founder photograph from ProGenEDA and Type2Learn, documented in [BRAND-IMAGERY.md](BRAND-IMAGERY.md).
