## Evidence boundaries

- Both research projects remain explicitly **unpublished / in progress**. Prepared rewrite requests are not reported as completed analysis.
- The Claude document is an **application CV**, not proof of appointment.
- P@SHA is a **finalist selection**, not a Gold award.
- Ten future workshops are a **plan**, not a completed count.
- The CV's **1,000 verified validation examples** and the GitHub profile's **7,000+ circuit library** are separate claims, not interchangeable counts.
- CPU contribution is described as **team work with specific owned modules**, not sole authorship of every subsystem.
- Education end dates remain expected where appropriate. Community-role dates follow the more recent supplied CVs when the old LinkedIn transcription differs.
- Private repositories cannot be enumerated by the public API. The complete public snapshot is timestamped in `app/github-repositories.json`; it refreshes through `npm run sync:github`.
- Forks are explicitly labeled. Public repository descriptions are sourced from GitHub; no description is invented for an undocumented repository.

The main page introduces the story and links to chapters. It does not flatten certifications, achievements, projects and education into one long résumé page. Final section ordering can be changed independently of this coverage.
